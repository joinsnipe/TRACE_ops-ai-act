# Contributing

Contributions are welcome if they preserve the core principle: **signal, not verdict**.

Good contributions:

- better tokenization;
- lower false positives;
- clearer rule descriptions;
- additional examples;
- SARIF output;
- JS/TS parsing;
- docs improvements.

Avoid:

- claiming legal certification;
- adding unsupported legal conclusions;
- embedding proprietary TRACE/SPE scoring;
- adding rules that overclaim based on weak keywords.
